### What I learned

For this project I decided to use fixed-width layout instead of responsive layout.  I'm really not sure why I'd use fixed-width layout seeing as how websites need to be viewed across many screen sizes, but I thought it would be useful to try.  I thought the result was fine for a project like this, but I suspect more complex websites being designed much easier using responsive layout.

One thing I learned is how awkward and potentially unhelpful the git messages were for a simple project like this.  I just wanted to sit down and design wherever my attention grabbed me, I didn't think it was valuable to plan it out so that I could have useful commit messages, and I felt it wasn't the most useful for such a simple project that I completed in two days.  With that being said, I feel that more compelex projects being immensily benefited from proper planning.  

A final thing that comes to my mind is I need to figure out a better system for organizing and implementing my css.  For a simple project as this one, I didn't have a problem because I didn't plan it out, but I can see rules being overlooked and rules being implemented in one place where they something else was implemented in another and causing me a lot of confusion.  

### AI Collaboration

I used ChatGPT to ask questions after I implemented something and it didn't work as I thought it would.  Sometimes, I'd seach for a solution on the internet, and I'd read an article or a blog post or something.  Sometimes that was useful, sometimes it was more time efficient to just ask ChatGPT.  For now, I'm happy to use it to ask questions when I get confused about something, but I plan on using it less once I get more experienced with frontend development.
